## ⚡ 快速部署

**1. 上传全部文件到服务器**（或宝塔面板直接解压）

**2. 新建数据库**

```sql
CREATE DATABASE navigation CHARSET utf8mb4;
```

**3. 修改数据库配置** `admin/config.php`

```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'navigation');
define('DB_USER', 'navigation');   // 改成你的用户名
define('DB_PASS', 'navigation');   // 改成你的密码
```

**4. Nginx 配置**（关键一步）

```nginx
location ~ \.php$ {
    fastcgi_pass 127.0.0.1:9000;
    fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    include fastcgi_params;
}
```

**5. 访问**

- 前台：`http://你的域名/`
- 后台：`http://你的域名/admin/`
- 账号：`admin`　密码：`admin123`

> ⚠️ 首次登录后立刻改密码！

## 🌙 为什么选这个项目？

- **快**：全静态HTML，PHP仅负责数据接口，毫秒级响应
- **轻**：整个项目不到 2MB，部署简单，迁移方便
- **稳**：PHP+MySQL，经典组合，服务器要求极低
- **美**：移动端优先设计，骨架屏+动画+深色金配色，质感在线
- **灵活**：所有内容后台可改，不用动代码
